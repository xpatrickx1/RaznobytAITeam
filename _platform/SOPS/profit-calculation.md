# SOP: розрахунок прибутку

**Роль:** Growth Manager. **Вихід:** `WORKSPACE/growth-manager/pnl_ГГГГ-ММ-ДД_<період>.md` і `WORKSPACE/growth-manager/products/<slug>/unit-economics_ГГГГММДД.md`. Нова версія = новий файл. Не вигадувати тарифи, комісії, ставки податків і курси.

## Модель показників

| Рівень | Формула | Примітка |
|---|---|---|
| 1. **Підтверджена виручка** | Сума замовлень, які викуплені/оплачені, мінус повернення і невикуп | Замовлено ≠ виручка. При післяплаті виручка підтверджується викупом |
| 2. **Валовий прибуток** | Підтверджена виручка − закупівельна вартість проданих (не повернутих) товарів | Закупівельні ціни від Supplier Manager |
| 3. **Маржинальний прибуток до реклами** | Валовий прибуток − змінні витрати виконання | Змінні: доставка (у т.ч. зворотна), комісії оплати/післяплати, упаковка, збори платформ, втрати від відмов і повернень |
| 4. **Чистий операційний прибуток** | Маржинальний до реклами − рекламні витрати − постійні операційні витрати періоду | Постійні: підписки, інструменти, домени, платформа магазину тощо |
| 5. **Податки та обов'язкові платежі** | **Окремий рядок/блок, не входить у п. 4** | Значення й правила дає CEO/бухгалтер. Агент не надає податкових порад |

Якщо CEO надав дані про податки, окремо показати «Чистий результат після податків та обов'язкових платежів». Без даних: `[НЕВІДОМО]`.

## Вхідні дані

| Дані | Джерело | Якщо немає |
|---|---|---|
| Замовлення, статуси викупу/відмови/повернення | `DATA/inbox/orders/` | Блокер розрахунку |
| Закупівельні ціни | результат Supplier Manager з джерелом | `[НЕВІДОМО]` |
| Доставка, комісії післяплати й оплат, упаковка | `DATA/inbox/costs/` (договори/тарифи від CEO) | `[НЕВІДОМО]` |
| Рекламні витрати | `DATA/inbox/ads/` (валюта, період) | `[НЕВІДОМО]` |
| Курс валют для витрат у іноземній валюті | офіційне джерело, дата курсу | `[НЕВІДОМО]` |
| Постійні витрати | `DATA/inbox/costs/` | `[НЕВІДОМО]` |
| Податки та обов'язкові платежі | від CEO/бухгалтера | `[НЕВІДОМО]` |

## Правила
1. Один закритий період для всіх даних звіту. Неповні періоди не змішувати з повними.
2. **Невідомі витрати не вважати нулем.** Якщо хоча б один обов'язковий вхід `[НЕВІДОМО]`, звіт має статус **`ПОПЕРЕДНЬО`**, а показники, що від нього залежать, позначаються `[НЕВІДОМО]` або наводиться діапазон із зазначенням, що саме не враховано.
3. Повернення й невикупи після закриття періоду коригуються **наступним** звітом, а старий не переписується.
4. Прибуток рахувати **за замовленнями й фактичними витратами**, а не за показниками рекламного кабінету.
5. Валюта: усе приводити до гривні за зафіксованим курсом із джерелом і датою.
6. Кожне число має мітку (`[ФАКТ]`, `[РОЗРАХУНОК]`, `[ПРИПУЩЕННЯ]`, `[НЕВІДОМО]`) і джерело (`STANDARDS.md`).

## Беззбитковість товару
- **Маржинальний прибуток на замовлення до реклами** = ціна продажу − закупівельна вартість − змінні витрати виконання (з урахуванням очікуваної частки повернень/невикупів; частка береться з фактичних даних, інакше `[НЕВІДОМО]`).
- **Беззбитковий CPA** = маржинальний прибуток на замовлення до реклами.
- **Беззбитковий ROAS** = ціна продажу ÷ беззбитковий CPA.
- Результат передається Ads Manager і CEO як вхід для рекомендацій (`ads-management.md`).
- Беззбиткові значення рахуються по товару з фактичних даних. **Цільові CPA/ROAS, мінімальна вибірка й тестовий бюджет CEO поки не задані**: `[НЕВІДОМО]`, універсальних значень немає.
