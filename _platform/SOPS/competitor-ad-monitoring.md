# SOP: моніторинг реклами конкурентів

**Роль:** Product Researcher (власник). Creative Director читає. **Вихід:** `WORKSPACE/product-researcher/competitor-ads/snapshot_ГГГГММДД.md` + (якщо є попередній знімок) `changes_ГГГГММДД.md`. Skill `ads` не використовується.

## Межі
- Лише публічні дані, які CEO чи роль бачать без обходу обмежень. Не входити в чужі акаунти, не обходити блокування, не купувати дані.
- Не контактувати з рекламодавцями. Не копіювати чужі тексти й зображення: креативи лише як спостереження.
- **Автоматичний моніторинг не заявляється й не запускається**, доки не перевірено можливості Cowork і CEO не погодив це окремо. Жодних автоматичних збирачів і інтеграцій. Джерела: ручний перегляд публічних сторінок реклами, сайтів і маркетплейсів; скріншоти/експорти від CEO у `DATA/inbox/competitor-ads/`.
- Перегляд публічної реклами **не доводить прибутковість**. Тривалий показ ≠ успіх; відсутність реклами ≠ слабкий товар.

## Періодичність і виконання
- Початково **раз на тиждень** на кожен товар/нішу в роботі (рішення CEO, 2026-11-13); змінює лише CEO.
- Публічну рекламу **поки переглядає CEO разом із Product Researcher**: CEO відкриває сторінки й надає скріншоти/нотатки у `DATA/inbox/competitor-ads/`, Product Researcher структурує спостереження за таблицею нижче. Самостійний перегляд агентом можливий лише після перевірки можливостей Cowork і погодження CEO.

## Що фіксувати (запис про рекламодавця)

| Поле | Значення |
|---|---|
| Рекламодавець / сторінка | назва, посилання |
| Вперше побачено нами | дата першого знімка (не «дата запуску» реклами) |
| Товар / ніша | slug з `DATA/products-index.md` або опис |
| Формат | статичне / відео / карусель / інше |
| Хук і головна обіцянка | своїми словами, 1 рядок |
| Пропозиція | ціна, подарунок, знижка: лише те, що видно, з датою |
| Куди веде | сайт/маркетплейс/месенджер |
| Кількість варіантів | скільки різних оголошень бачимо |
| Видимий строк показу | у днях, з датою спостереження |
| Мова / регіон | що видно |
| Статус | `ФАКТ` (видно) / `ПРИПУЩЕННЯ` (висновок) |
| Джерело, дата | обов'язково |

## Кроки
1. Взяти список товарів/ніш із завдання та попередній `snapshot` (якщо є).
2. Занести спостереження за таблицею. Висновки відокремити від фактів.
3. **Новий рекламодавець** = відсутній у попередніх наших знімках. Позначати так: «новий у наших спостереженнях», а не «щойно з'явився на ринку».
4. **Зміни** (`changes_`): нові рекламодавці, зникли, змінилась пропозиція/ціна, нові формати.
5. **Оцінка перспективності для України** (ідея для CEO, не рішення): скільки конкурентів, наскільки різноманітні кути, видима ціна, чи є пропозиція, що підтверджено про попит; впевненість висока/середня/низька. Без вигаданих цифр.
6. Передати Creative Director перелік хуків/кутів **як спостереження** для власних оригінальних ідей.
7. Рекомендація: `продовжити дослідження` / `пауза` / `відхилити` + що ще треба підтвердити.

## Мінімальний звіт (до 1 екрана)
- Охоплення: що переглянули, коли, чого не вдалося побачити (`[НЕВІДОМО]`).
- Таблиця спостережень.
- Нові/зниклі рекламодавці.
- Висновки (`[ПРИПУЩЕННЯ]`) і рекомендація.
- Джерела.
