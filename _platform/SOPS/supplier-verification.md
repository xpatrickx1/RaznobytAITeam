# SOP: перевірка постачальника

**Роль:** Supplier Manager. **Вихід:** `WORKSPACE/supplier-manager/suppliers/<supplier>/supplier-eval_ГГГГММДД.md` (нова версія = новий файл). Ідентифікатор постачальника (`s-NNNN_<назва>`) присвоює Director у завданні.

## Межі
- Не контактувати з постачальником, не замовляти, не платити, не підписувати нічого. Лише аналіз і **чернетки** листів/запитань для CEO.
- Не вигадувати ціни, умови, відгуки, наявність, терміни. Невідоме: `[НЕВІДОМО]`.
- Тестове замовлення, передоплата, угода: лише за погодженням CEO (`APPROVALS.md`).

## Вхід
Завдання Director, документи й умови з `DATA/inbox/suppliers/`, публічні джерела (сайт, відгуки, реєстри). Кожен факт з джерелом і датою.

## Кроки
1. **Ідентифікація:** хто саме постачальник (назва, юридична/торгова особа, сайт, контакти), чим підтверджено. Незбіг або нестача даних: `ТРИВОЖНО`.
2. **Заповнити скор-картку** (нижче): кожен критерій має статус `ПІДТВЕРДЖЕНО` / `НЕ ПІДТВЕРДЖЕНО` / `НЕВІДОМО` / `ТРИВОЖНО`, значення, джерело, дату.
3. **Альтернативи:** знайти щонайменше одного резервного постачальника для товару або записати `[НЕВІДОМО]`, чому не знайдено.
4. **Список питань** до постачальника (чернетка для CEO) по всіх критеріях зі статусом `НЕВІДОМО`.
5. **Висновок-рекомендація** (рішення за CEO): `до пілоту` / `умовно, після уточнень` / `відхилити` + 3–5 рядків обґрунтування, рівень впевненості.

## Скор-картка

|---|---|---|---|---|
| Ідентифікація | Реальна особа/компанія, контакти, відповідність у різних джерелах | | | |
| Умови дропшипінгу | Чи працює без закупівлі наперед, мін. замовлення, плата, брендування, формат передачі замовлень | | | |
| Закупівельна ціна | Ціна за одиницю, що входить, коли змінюється, як повідомляє про зміну | | | |
| Наявність | Звідки дані про залишки, як часто оновлюються, що при вичерпанні | | | |
| Доставка | Хто відправляє, строки, перевізники, тариф, трекінг | | | |

## Червоні прапорці (достатньо одного для статусу `ТРИВОЖНО` у висновку)
- Не можна підтвердити, хто постачальник.
- Відмова фіксувати умови письмово або відповіді, що змінюються.
- Тиск терміновістю, вимога оплати без зрозумілих умов.
- Невідомо, хто відповідає за брак і повернення.
- Ціна істотно нижча, ніж у порівнянних пропозицій, без пояснення (порівняння лише з перевіреними даними).
- Відгуки лише на сайті самого постачальника.

## Правила якості
- Порівнювати постачальників за однаковою карткою.
- Не оцінювати «за враженням»: лише факти з міткою `[ФАКТ]`; висновки з `[ПРИПУЩЕННЯ]`.
- Закупівельну ціну та тарифи передавати Growth Manager через файл результату, не повторюючи розрахунків.
