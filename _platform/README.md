# _platform: знімок спільних ресурсів AI-Company

Цю теку заповнюють **лише** копіюванням випуску платформи; вручну її не редагують. Склад і версії: `PLATFORM_VERSION.md` (створюється разом із випуском): `platform_release`, версії CORE, ролей, SOP, Skills, список файлів із SHA-256, дата збирання, джерело.

## Оновлення
1. CEO отримує новий випуск з AI-Company.
2. Копіює потрібні файли в цю теку й замінює `PLATFORM_VERSION.md`.
3. Звіряє SHA-256 файлів із `PLATFORM_VERSION.md`; розбіжність: зупинка й повідомлення CEO.
4. Director бізнесу оновлює binding (`platform_release`, версії); MAJOR-зміна потребує звіту сумісності й підтвердження CEO; усі версії бізнесу змінюються разом.

Нічого не синхронізується автоматично. Пропозиції змін платформи: `REPORTS/platform-proposals/`.
