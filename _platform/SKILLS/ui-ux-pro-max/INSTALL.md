## Стан
- Файли Skill **скопійовано в репозиторій** (`SKILL.md`, `data/`, `references/`, `scripts/`). Skill **не встановлено** як плагін чи CLI, **не активовано**, скрипти **не запускались**.
- За `SKILL.md`, потрібен лише Python 3 без зовнішніх залежностей; CLI (`npm`, `uipro`) для роботи з локальними файлами не потрібен. Згадки про `npm install -g ui-ux-pro-max-cli` і `uipro init` походять із вторинних описів і в цій копії не підтверджені `[ПРИПУЩЕННЯ]`.
- Статус у бібліотеці: **NEEDS REVIEW**. Не включати до затвердженого релізу платформи.

1. Перевірити ліцензії компонентів і даних: шрифти (`data/google-font-licenses.json`), іконки Phosphor (`data/phosphor-icons-upstream.json`); отримати текст `LICENSE` upstream.
2. Уточнити походження сторонніх матеріалів у `data/`.
3. Актуальність цього файлу й `source-reference.md`: виправлено 2026-11-15.
4. Перевірити шлях запуску для нашого середовища: `SKILL.md` використовує `${CLAUDE_PLUGIN_ROOT}/.claude/skills/ui-ux-pro-max/scripts/search.py`. У нашій структурі скрипти лежать у `SKILLS/ui-ux-pro-max/scripts/`; відповідність шляху не перевірена.
