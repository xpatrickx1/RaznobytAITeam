# Raznobyt: робоча тека бізнесу

Продаж технічних і спеціальних тканин бізнесам (https://raznobyt.com/); мета: залучати нових клієнтів і нарощувати продажі через інтернет-маркетинг, насамперед Google. Окремий Claude Project: рознобит. Платформа AI-Company (правила, ролі, Skills, SOP) лежить у `_platform/` (лише читання); тут дані й результати цього бізнесу. Доступи й рівні даних: `ACCESS.md`.

## Склад команди
Operations Director (керує завданнями), Product Researcher (ніша, клієнти, конкуренти), Sales Manager (продажі, кваліфікація, скрипти), Growth Manager (воронка, економіка, плани зростання), Creative Director (контент і тексти), Ads Manager (Google Ads, тести), Store Builder (оптимізація сайту, SEO на сторінці, конверсія). Supplier Manager підключається пізніше.

## Як це працює
1. Ви ставите ціль Director у його сесії.
2. Director створює файли завдань у `TASKS/open/` для потрібних ролей (він сам нікому не пише й нічого не запускає).
3. Ви відкриваєте **нову сесію** потрібної ролі й даєте їй промпт нижче. Роль кладе результат у свою теку `WORKSPACE/<роль>/`.
4. Ви повертаєтесь у сесію Director: він приймає результат, оновлює `STATUS.md`, готує звіт і наступні завдання.
5. Усі зовнішні дії (листування, дзвінки, платежі, реклама, публікації) виконуєте лише ви.

## Промпт початку сесії ролі
```
Ти <Роль> бізнесу Raznobyt. Прочитай лише: _platform/CORE/README.md (розд. 6), _platform/APPROVALS.md (розд. 1–4), _platform/LIBRARY/roles/<role>.md, TEAM/<role>.md і завдання TASKS/open/<ID>*.md. Виконуй завдання в межах своїх прав, результат клади у WORKSPACE/<role>/. Невідоме позначай [НЕВІДОМО], нічого не вигадуй, зовнішніх дій не виконуй.
```
Для Director додайте: «Створюй завдання за `_platform/TEMPLATES/task.md`, приймай результати за `_platform/TEMPLATES/acceptance-checklist.md`».

## Початок
1. Відкрийте `PROFILE.md` і виправте/підтвердіть чернетку (зокрема ціль із числами, географію, канали).
2. Відкрийте сесію Director і дайте перше завдання (приклад нижче).

**Перше завдання Director (приклад):** «Склади план перших 30 днів залучення оптових клієнтів для Raznobyt: які завдання дати Product Researcher, Sales Manager, Growth Manager; без зовнішніх дій; створи файли завдань у TASKS/open».

## Правила
- Не класти в теку клієнтську базу, CRM-експорти з іменами й контактами, паролі, платіжні дані (К3).
- `_platform/` не редагувати (цілісність: `_platform/PLATFORM_MANIFEST.sha256`).
- Пропозиції змін платформи: `REPORTS/platform-proposals/`.
