## Що зробити (номери розділів ТЗ)
1. **Завдання 1. Редирект через http:** посилання меню, шапки й футера з кінцевим слешем (14 UA/RU); `absolute_redirect off;` і 301 з `/catalog/personal`, `/catalog/fire`. Якщо конфігу nginx немає в `{SITE_CODE}`, підготувати готовий фрагмент конфігу файлом у `WORKSPACE/web-developer/` з інструкцією для CEO.
2. **Завдання 2. Кешування:** `Cache-Control: no-cache` для HTML, `sitemap.xml`, `robots.txt`; довгий кеш лише для `/assets/`. Конфіг nginx: як у п. 1.
3. **Завдання 3. Title і description карток** за шаблоном ТЗ (UA і RU), доповнити короткі description.
4. **Завдання 4. Пагінація категорій:** товари посиланнями в HTML сервера, `?page=N` із self-canonical і hreflang, `?page=1` → 301, `?page` поза межами → 404, без `?page` у sitemap.
5. **Завдання 5, частина «зараз»:** прибрати 10 URL `/catalog/unknown/` із sitemap. Перенесення товарів робити лише після рішення CEO.
6. **Завдання 6. Дрібні правки:** http-відео, українські рядки на RU-сторінках, бренд двічі в title, alt, meta keywords, `lastmod`.
7. **Не робити:** завдання 7 ТЗ (склад тканин, чекає даних від CEO); дублі тканин між категоріями, JSON-LD і тексти категорій (окремі завдання).
8. **Не зламати** розділ ТЗ «Що вже працює»: canonical, hreflang, `html lang`, картки в сирому HTML на всіх 666 URL.
