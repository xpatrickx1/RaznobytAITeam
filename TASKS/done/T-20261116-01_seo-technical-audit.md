# Технічний і on-page SEO-аудит raznobyt.com

## Ціль
Визначити, що заважає сайту з'являтися в Google за комерційними запитами, і дати пріоритетний список виправлень для CEO та Store Builder.

## Вхідні файли (лише читання)
- `PROFILE.md`: поля «Опис діяльності», «Географія роботи», «Маркетингові канали»
- Публічний сайт https://raznobyt.com/ (UA і RU версії, головна, `/catalog/` і категорії, 3–5 карток товарів)
- Спостереження Director (2026-11-16, головна): title «Головна | Різнобит»; H1 «Закінчилась тканина — зупинилось виробництво» (без ключових слів); у статичному HTML лічильники показують «0»; хешовані файли в `/assets/` вказують на JS-збірку (можливий клієнтський рендеринг); у меню `/catalog/fire`, у футері `/catalog/fire-safety`; robots.txt для Director недоступний `[НЕВІДОМО]`
- Skills за каталогом `_platform/SKILLS/CATALOG.md`: analytics (OV-AN), cro

## Очікуваний результат
- Файл: `WORKSPACE/seo-specialist/T-20261116-01_result.md` (шаблон `_platform/TEMPLATES/result.md`)
- Розділи:
  1. Індексація й рендеринг: robots.txt, sitemap.xml, чи віддає сервер контент без JS (SSR/SPA), canonical, hreflang UA/RU, коди відповіді, дублі URL.
  2. On-page: title, description, H1–H2 для головної, каталогу, кожної категорії й зразка картки; таблиця «було → пропозиція».
  3. Структура: категорії й ЧПУ, внутрішня перелінковка, хлібні крихти, розмітка (Organization, LocalBusiness, Product, FAQ) як рекомендація.
  4. Швидкість і мобільна версія: спостереження з публічних інструментів або `[НЕВІДОМО]`.
  5. Пріоритетний список виправлень (до 15 пунктів): вплив / складність / хто готує (SEO, Store Builder, Creative Director) / що робить CEO.
  6. Перелік даних, які CEO має надати з Google Search Console й Analytics (знеособлені експорти: покриття індексу, запити, сторінки за 3–6 міс.).

## Критерій завершення
- Відповідь «так / ні / `[НЕВІДОМО]`» на питання, чи Google може прочитати контент сторінок без JS, з доказом (джерело, дата).
- Є таблиця on-page для всіх основних категорій.
- Список виправлень пріоритезований і кожен пункт має виконавця.

## Не рахується як результат
Загальний SEO-чекліст без перевірки саме цього сайту; обіцянки позицій чи термінів; оцінки трафіку без даних; висновки без джерела й дати.

## Коли зупинитись і повернутись до Director/CEO
- Бракує даних (`[НЕВІДОМО]`) або вони застарілі/сумнівні
- Потрібна дія із `APPROVALS.md`, розд. 2–3 (платіж, контакт, публікація, дії в кабінеті, доступи)
- Завдання, Skill чи джерело вимагає забороненої дії
- Для перевірки потрібен доступ до Search Console, адмінки сайту чи платного інструмента: записати як запит до CEO, не просити доступ
